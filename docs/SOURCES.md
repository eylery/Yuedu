# 文字书源格式与验证范围

本应用独立实现 Legado 文字书源的导入和运行组件。首次启动不预置外部联网书源，可从「书源 → ＋」导入 JSON 文件或网址合集。点开书源可编辑和导出 JSON，进入「登录与设置」或浏览发现分类。

**配置已保存、配置检查通过、网站实际可用，是不同的状态。** 导入不执行第三方脚本，也不联网检查其中的网站；使用搜索、阅读、发现或登录功能时才运行相应规则。缺少规则、网站改版、账号权限或访问验证仍可能在运行时产生错误。

本次提供的合集有 391 项，按 `bookSourceType` 离线分类后，保留 **342 个文字源**，排除 **49 个漫画、有声、视频等非文字源**。这个数量不代表全部网站已经端到端通过。第三方合集未作为内置书源或测试资源分发。

## 导入与原始配置保留

顶层可以是一个书源对象或对象数组。导入文件、网址下载和 JSON 解析统一限制为 **50 MB（50,000,000 字节）**，每批最多 **10,000 项**。下载大小限制包含自动解压后的响应正文；普通网页和脚本请求另有 8 MB 上限。

- 保存需要非空字符串 `bookSourceName` 和 `bookSourceUrl`。缺少名称或标识、字段类型错误、非对象条目会逐项跳过。
- `bookSourceUrl` 是书源身份标识，可以是非网址字符串；真正发起网络请求时，规则必须生成有效的 HTTP / HTTPS 网址。
- `bookSourceType` 缺省或为 `0` 时按文字源处理；其他类型不加入文字源库，单独计入「已排除」。
- 结构有效的文字源保留原有启停设置。JavaScript、POST、XPath、分页或登录配置本身不会导致自动停用。运行字段的结构不合法时，配置保留并停用，报告原因。
- 导入报告区分已保留、配置通过检查、已停用、无效跳过和非文字排除。「＋ → 上次导入详情」可查看当前会话中的最近报告。

文件读取和解析在后台进行，完成批次解析后才合并、原子写入。无效 JSON、错误顶层类型、超限、读取失败或提交前取消不会写入部分批次。逐项跳过无效条目属于正常批次处理，不影响其他有效项。

完全相同的 `bookSourceUrl` 更新已有书源并保留 ID；同一网站下不同的标识不会合并。未知字段、嵌套对象、数组、脚本和扩展元数据会保留到编辑器和导出 JSON。导出重新序列化 JSON，并维护应用的 `id`、`enabled` 等字段，因此不保证字节、缩进或字段顺序与原文件相同。配置保留也不表示其中所有扩展功能均有对应界面。

## 字段与阅读流程

| 配置 | 用途 |
| --- | --- |
| `searchUrl`、`ruleSearch` | 搜索请求、列表及书名、作者、详情网址等字段 |
| `ruleBookInfo` | 详情页初始化、元数据和目录网址 |
| `ruleToc` | 目录、章节字段、倒序、更新前脚本和 `nextTocUrl` |
| `ruleContent` | 正文、子内容、标题、替换、回调、`webJs` 和 `nextContentUrl` |
| `exploreUrl`、`ruleExplore` | 发现分类及分页列表；缺省时可使用搜索列表规则 |
| `header`、`concurrentRate` | 动态或静态请求头、书源请求间隔 / 并发速率 |
| `loginUrl`、`loginUi`、`loginCheckJs` | 登录操作、设置表单、响应登录检查 |
| `jsLib`、`variableComment` | 脚本库和书源变量说明 |

书源可以只提供发现而没有搜索；保存时不强求所有阅读阶段均完整。真正使用缺失的功能时会显示错误。相对链接以实际响应网址解析，支持请求选项随链接保留。

目录和正文分别跟随 `nextTocUrl` / `nextContentUrl`，检测重复网址以避免循环。目录支持倒序和重复章节去重；正文多页合并后进行替换和纯文本处理。章节首次打开后缓存在本机，之后可以离线复读。当前综合搜索界面取各书源第一页；引擎支持 `page` 参数，发现分类界面提供继续加载。

## 规则能力

规则解释器在 WebKit 中运行，覆盖以下形式。不同语法的细节仍以实现和回归测试为准，不等同于完整复刻 Android 运行环境。

| 类型 | 已实现形式 |
| --- | --- |
| CSS / Legado 选择链 | `@css:`、`@` 串联、`class.` / `id.` / `tag.` / `text.`，标准 CSS 及常见 Jsoup `:contains` / `:matches` / `:has` 等扩展 |
| 索引 | 正负索引、多个索引、范围切片和排除索引；CSS 与 JSONPath 切片遵循各自的语法 |
| 字段提取 | `text`、`ownText`、`textNodes`、`html`、属性值；支持当前元素提取 |
| XPath | `@XPath:` 或 XPath 路径，使用 WebKit 的 XPath 求值 |
| JSONPath | `@json:`、字段 / 引号键、通配符、正负索引、联合、切片、递归、过滤表达式及已实现的聚合函数 |
| 组合 | `&&` 合并、`\|\|` 回退、`%%` 交错，以及规则中的动态模板 |
| 变量 | `@put:` / `@get:`、`{{…}}`，书源、书籍和章节上下文 |
| 脚本 | `@js:`、`<js>…</js>`、规则与脚本串联、内联或网址形式的 `jsLib` |
| 正则 | `##` 删除 / 替换、捕获组、首次匹配形式、正则列表提取、正文 `replaceRegex` |

例如：

```json
{
  "bookList": "class.book-list@tag.li",
  "name": ".bookname@a@text##书名：",
  "author": "span[0]@a@title",
  "bookUrl": "tag.a.-1@href"
}
```

JSON 列表可使用 `@json:$.books[*]`，列表字段相对于当前项，例如 `$.name`、`$.url`。字段正则支持 `##作者：(.+)##$1`；对 `@html` 的替换发生在最终正文转为纯文本之前。Java 正则的一些常见形式会转换，但不保证支持所有 Java 正则扩展。无效选择器或表达式会在执行时报告错误。

普通 HTML 在脱离运行页面的文档中解析，不把远程 DOM 插入宿主页面，也不自动执行网页脚本。书源明确要求 `webView` / `webJs` 时，使用独立的网页浏览环境获取渲染结果。

## 请求、登录与运行状态

请求网址支持 `{{key}}`、`{{page}}` 和脚本表达式；可附加 JSON 请求选项，例如：

```json
{
  "searchUrl": "/search,{\"method\":\"POST\",\"body\":\"keyword={{key}}&page={{page}}\",\"charset\":\"GBK\"}"
}
```

支持 GET / POST / HEAD、字符串或 JSON 正文、字符集、请求头、超时、重定向控制、请求脚本以及网页渲染选项。查询和表单内容按指定字符集编码；支持 UTF-8、GBK / GB2312 / GB18030、Big5 等系统可识别编码。

`header` 可为对象、JSON / 对象文本或返回请求头的脚本；与登录头、请求级头合并后发送。支持 `User-Agent`、`Referer`、`Cookie`、`Authorization` 等站点需要的字段，拒绝控制字符以及 `Host`、`Content-Length` 等连接管理字段。跨主机重定向会移除原始认证头和 Cookie，再应用目标主机的 Cookie。

Cookie 按书源隔离并遵循域名、路径、过期和安全属性保存。`enabledCookieJar` 控制 HTTP 响应 Cookie 的自动保存；已有 Cookie、脚本 Cookie API 和网页登录 Cookie 同步独立保留。书源变量、登录信息、脚本缓存和书籍上下文也按书源持久化；脚本的文件接口仅能读取其自身下载缓存，不能访问任意应用文件。

「登录与设置」呈现 `loginUi` 的输入框、选项和操作按钮，并提供书源变量编辑。登录脚本、验证码输入、图片验证码和网页验证可从该入口完成。普通搜索 / 阅读不会自动弹出登录浏览器；需要交互时会提示用户进入设置。`loginCheckJs` 可检查响应并更新登录状态。应用不自动调用付费购买规则，也不替用户购买章节。

## JavaScript 宿主和系统工具

脚本可使用适配后的 `java`、`source`、`book`、`chapter`、`cookie`、`cache` 接口，处理网络请求、规则提取、变量、响应对象、登录状态和缓存。`jsLib` 可载入内联脚本或通过受限网络接口下载库；远端库的实际版本及运行行为仍需按站点验证。

系统工具提供 Base64 / Hex、字符编码、MD5 / SHA 摘要、AES / DES / 3DES、HMAC、RSA、简繁转换、时间格式、中文章节号和 UUID。密码学使用 CommonCrypto / Security，字体映射使用 CoreText，图像像素读取使用 ImageIO / CoreGraphics；无第三方运行依赖。

为现有书源提供一组 Java 风格适配，包括 `Cipher` / `Mac`、密钥和 IV、Base64、集合、字符串、字节流、Jsoup 常用方法，以及部分 Android Cookie / Bitmap 接口。`Packages` / `JavaImporter` 仅暴露这些明确实现的对象；没有 JVM、任意 Java / Android 类加载、反射或操作系统命令执行。

字体接口已实现基于字形轮廓的映射，但**未验证真实字体混淆站点**；动态远端脚本库也**未完成实站验证**。这些接口的存在不能作为所有相关书源可用的证明。

## 网络与执行边界

每次规则操作使用独立 WebKit 运行上下文。宿主页面通过 CSP 禁止直接网络连接、远程图片和框架加载，并禁止导航；脚本网络请求必须经过明确的原生桥接接口。登录 / 渲染网页使用另一个浏览环境，站点页面不会获得书源宿主桥接。

为支持用户定义的普通 HTTP 书源，工程启用了 ATS `NSAllowsArbitraryLoads`。这允许明文 HTTP；**HTTPS 的系统 TLS 证书验证仍保留**，没有接受任意证书或跳过证书验证的实现。

| 边界 | 当前上限 |
| --- | --- |
| 导入合集 | 50,000,000 字节、10,000 项 |
| 普通 HTTP 响应 / 请求正文 | 8,000,000 字节 |
| 普通 HTTP 超时 | 默认请求 30 秒、资源 60 秒；规则请求超时限制在 1–90 秒 |
| 单次规则操作 | 默认 120 秒；交互登录 600 秒，可取消 |
| 单次规则操作网络请求 | 300 次原生请求调用 |
| 目录或正文分页 | 各最多 200 页 |
| 目录 | 最多 20,000 章 |
| 单次选择结果 | 30,000 项；JSONPath 嵌套最多 64 层 |
| 搜索 / 发现每页 | 每源最多 100 条结果；综合搜索同时处理最多 3 个源 |

达到限制会停止相应操作并报告错误。网页渲染的资源加载由独立 WebKit 处理，不能把普通 URLSession 的正文上限理解为整页所有子资源的总下载限额。

## 本地流程与验证记录

在工程根目录运行：

```sh
python3 scripts/demo_source_server.py
```

在 **iPhone 模拟器**的「书源 → ＋ → 从网址导入」输入 `http://localhost:8080/source.json`，随后到发现页搜索「春日」，把《春日手记》加入书架并阅读两章。两章为原创测试内容。已打开的正文可在关闭服务或停用书源后复读。

`/mixed-sources.json` 提供包含普通文字源、脚本文字源、无效项和漫画源的合成合集，用于检查逐项导入报告与原始配置保留。`Yuedu/Resources/example-source.json` 默认停用；本地服务返回启用版本。

服务默认仅监听 Mac 回环地址，模拟器可访问 Mac 的 localhost；实体 iPhone 的 localhost 指向手机自身，需另行提供手机可访问的服务。

静态能力分析脚本为 `scripts/analyze_source_collection.py`，只分析 JSON 和脚本文本，不执行第三方代码。[静态规则烟测](../scripts/LEGADO_RULE_SMOKE.md)可重现 5,118 条规则在合成 HTML / JSON 上的解析检查。构建、组件测试、模拟器流程及其实际结果统一见 [VALIDATION.md](VALIDATION.md) 的分阶段记录。本地服务测试、静态语法检查或配置逐字段比对，均不能替代 342 个真实站点的完整验证。
