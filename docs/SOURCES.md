# 文字书源格式与验证范围

本应用独立实现 Legado 文字书源的导入和运行组件。首次启动不预置外部联网书源，可从「书源 → ＋」导入 JSON 文件或网址合集。点开书源可编辑和导出 JSON，进入「登录与设置」或浏览发现分类。

**配置已保存、配置检查通过、网站实际可用，是不同的状态。** 导入不执行第三方脚本，也不联网检查其中的网站；使用搜索、阅读、发现或登录功能时才运行相应规则。缺少规则、网站改版、账号权限或访问验证仍可能在运行时产生错误。

本次提供的合集有 391 项，按 `bookSourceType` 离线分类后，保留 **342 个文字源**，排除 **49 个漫画、有声、视频等非文字源**。这个数量不代表全部网站已经端到端通过。第三方合集未作为内置书源或测试资源分发。

## 导入与原始配置保留

顶层可以是一个书源对象或对象数组。导入文件、网址下载和 JSON 解析统一限制为 **50 MB（50,000,000 字节）**，每批最多 **10,000 项**。下载大小限制包含自动解压后的响应正文；普通网页和脚本请求另有 8 MB 上限。

- 保存需要非空字符串 `bookSourceName` 和 `bookSourceUrl`。缺少名称或标识、字段类型错误、非对象条目会逐项跳过。
- `bookSourceUrl` 是书源身份标识，可以是非网址字符串；真正发起网络请求时，规则必须生成有效的 HTTP / HTTPS 网址。
- `bookSourceType` 缺省或为 `0` 时按文字源处理；其他类型不加入文字源库，单独计入「已排除」。
- 结构有效的文字源保留原有启停设置。JavaScript、POST、XPath、分页或登录配置本身不会导致自动停用。运行字段的结构不合法时，配置保留并停用，报告原因。
- 导入报告区分已保留、配置通过检查、已停用、无效跳过和非文字排除。「＋ → 上次导入详情」可查看当前会话中的最近报告。

文件读取和解析在后台进行，完成批次解析后才合并、原子写入。无效 JSON、错误顶层类型、超限、读取失败或提交前取消不会写入部分批次。逐项跳过无效条目属于正常批次处理，不影响其他有效项。

完全相同的 `bookSourceUrl` 更新已有书源并保留 ID；同一网站下不同的标识不会合并。未知字段、嵌套对象、数组、脚本和扩展元数据会保留到编辑器和导出 JSON。导出重新序列化 JSON，并维护应用的 `id`、`enabled` 等字段，因此不保证字节、缩进或字段顺序与原文件相同。配置保留也不表示其中所有扩展功能均有对应界面。

## 字段与阅读流程

| 配置 | 用途 |
| --- | --- |
| `searchUrl`、`ruleSearch` | 搜索请求、列表及书名、作者、详情网址等字段 |
| `ruleBookInfo` | 详情页初始化、元数据和目录网址 |
| `ruleToc` | 目录、章节字段、倒序、更新前脚本和 `nextTocUrl` |
| `ruleContent` | 正文、子内容、标题、替换、回调、`webJs` 和 `nextContentUrl` |
| `exploreUrl`、`ruleExplore` | 发现分类及分页列表；缺省时可使用搜索列表规则 |
| `header`、`concurrentRate` | 动态或静态请求头、书源请求间隔 / 并发速率 |
| `loginUrl`、`loginUi`、`loginCheckJs` | 登录操作、设置表单、响应登录检查 |
| `jsLib`、`variableComment` | 脚本库和书源变量说明 |

书源可以只提供发现而没有搜索；保存时不强求所有阅读阶段均完整。真正使用缺失的功能时会显示错误。相对链接以实际响应网址解析，支持请求选项随链接保留。

目录和正文分别跟随 `nextTocUrl` / `nextContentUrl`，检测重复网址以避免循环。目录支持倒序和重复章节去重；正文多页合并后进行替换和纯文本处理。章节首次打开后缓存在本机，之后可以离线复读。在线搜索与发现分类均可继续加载分页，分页能力取决于书源对 `page` 参数的处理。

## 在线搜索增强

发现页右上角进入「搜索书籍」。搜索范围默认是全部已启用、具有搜索地址的文字书源；可按分组查找并批量选择，或逐个勾选。选择范围只作用于本次搜索页面，不修改书源启用状态。搜索后调整范围会使用原关键词重新搜索；换源续读自动排除原书源，仍按原书名筛选并保留章节匹配确认。

结果菜单支持综合匹配、书名包含、作者包含、书名完全匹配，以及相关度、书名、作者、书源顺序排序。匹配方式是对书源已返回结果的本地筛选，不会改变网站的搜索接口。可开启「合并同名同作者」，然后选择具体书源版本加入书架或阅读；缺少作者、标记未知作者或佚名的结果不会跨源合并，避免误认同一本书。默认保留各版本单独显示。

最多并行搜索 3 个书源，单次搜索请求预算为 30 秒，结果陆续显示。每个书源维护独立页码，成功后才推进；空页或没有新链接的重复页结束该源分页。失败保留此前结果并显示失败源、页码及原因，可仅重试失败源；停止后保留结果，再次加载继续未完成页。分页结束基于未经本地筛选的结果，所以第一页没有精确匹配时仍能查找后续页。书源被编辑、删除或停用时，相关结果与迟到回调失效，需要重新搜索才能加入新启用的书源。

搜索历史最多保留最近 20 个去重关键词，仅保存在本机。点击历史重新搜索，或直接清空；不自动生成热搜和推荐词。

## 缓存管理

入口为「我的 → 缓存管理」及「书籍详情 → 管理本书缓存」。仅管理在线书籍正文，本地导入书和示例书不参与清理。全局可查看已缓存章节、按 UTF-8 估算的正文大小、任务数量及待解析响应文件大小；估算不含 JSON 转义、目录、数据库和系统自身缓存，不等于应用总磁盘占用。

- 支持书名/书源搜索、全部/已缓存/未缓存完整/有任务/有失败筛选，以及按正文大小或书名排序。多选书籍可缓存、暂停或清理；本书列表支持章节名/序号搜索及多选章节缓存、清理。
- 单本可缓存全书、当前章节起 50 章或按目录位置指定起止范围。任务按章节 ID 保存，目录前插章节后仍定位原范围，已缓存正文自动跳过。每本书一次只运行一个范围；暂停后重新指定范围或仅重试失败，会替换原范围。
- 暂停保存任务范围和失败章节，停止相关系统传输并释放其临时响应文件；重启不会自动开始用户暂停的任务，可手动继续。后台挂起的活动任务仍在返回前台时自动恢复。失败章节及最多 30 条原因保留，可单独重试；点击失败章节可查看本书失败记录。取消任务保留已完成正文。
- 清理前展示章节数、估算大小并确认，先持久化取消相应下载任务，再原子清除所选正文。全书/所选章节清理保留书签元数据；「清理已读」仅清理当前章节之前的正文，并额外保留书签所在章节。清理不修改目录、阅读位置、书架分组、追更或换源版本关系。
- 清理同时使此前的阅读/下载请求失效，迟到结果无法重新写回缓存。重新打开已清理章节需要可用书源和网络，源失效的正文建议先备份。若任务取消或正文保存失败，会显示错误，原正文不被部分清除；任务取消成功但正文清理失败时，任务保持取消状态。
- 普通 GET 的系统后台下载、脚本/登录请求的前台处理及原有容量上限保持适用：单响应 8 MB、单书批量正文 100 MB、待解析响应 200 MB。本功能不自动清理登录 Cookie、书源脚本数据或本地原始文件。

## 换源完善

- 在「书籍详情 → 换源续读」查找其他已启用文字书源的同名作品；正文载入失败时也可直接进入，匹配当前失败章节。搜索结果提示作者是否一致，保留范围筛选、分页和失败重试。
- 「换源对比」显示两版书名、作者、书源、章节总数、末章和缓存数量。先按唯一章节名匹配，再统一中文/阿拉伯章号、全角、空白及标题边界标点；章号和标题须同时一致，重复标题、不同卷、拆章/合章、仅有章号时手动选章。目录支持章节搜索。手动选章默认从章首开始，也可主动沿用原章内比例。
- 选择章节后须成功试读才可确认。试读展示原始解析正文，提供完整原文页；每次网络请求最多等待 30 秒，可取消、重试或改选章节。空正文、失败、取消不写入书架；改选章节会清除上一次试读结果。书源变更或停用会使当前试读失效。书名/作者不一致或作者不明时，还须核对是否同一作品。
- 新版本继承原书的分组、置顶、阅读状态与追更开关，追更未读记录从新版本独立计算；可选择复制一一对应的书签，不能匹配的书签留在原书。原书进度、书签与正文缓存完整保留，旧源正文不会冒充新源缓存。新版本的正文净化仍按全局、新书源及该版本自身的规则范围执行，本书专用规则不会自动复制。
- 如果目标版本已在书架，使用它已保存的目录和缓存，确认后更新其续读位置，保留其管理设置和其他缓存，不重复添加同一源/网址。需要新目录时，先在该版本详情更新目录。确认时再次检查原书进度/目录和目标数据，变化则要求重选；书架、版本关联、试读正文、进度与书签一次性原子保存，写盘失败不发布部分变更。
- 「书籍详情 → 已保存版本」可按各自的进度返回其他版本，缓存章节可在书源停用后离线打开。各版本仍可在书架单独管理或删除，备份恢复保留版本关联。跨版本章内进度和书签为近似比例，不是逐字对齐，也不会静默自动切源。

## 正文净化

入口为「阅读页 → 设置 → 正文净化」，或「我的 → 正文净化」。净化发生在书源解析/本地导入之后的阅读显示阶段，不修改源规则、不回写章节缓存，也不需要重新下载已缓存的章节。这里的原文是书源规则已解析或本地已导入的正文，不是网站原始 HTML；已经被书源规则删除的内容不能由此恢复。

- 普通替换按字面匹配和替换，包括 `$` 与反斜线。正则替换使用系统 `NSRegularExpression`，支持 `$1`、`$2` 捕获组和 `(?m)` 等模式；替换留空表示删除。无效正则不能保存。
- 规则按列表从上到下执行，可启停、编辑、左滑删除，在编辑模式拖动排序。范围可选所有书籍、本书或同一书源。从阅读页新建规则默认限定本书；从「我的」新建默认全局。书籍/书源范围按 ID 匹配，不用书名做模糊匹配。
- 常用规则需主动添加：清理零宽空格、合并多余空行、清理重复章名。重复章名只匹配正文起始处与当前章节标题完全一致的一行；不扫描正文内相同文字。不自动猜测广告、作者说或求票段落，应自行添加准确规则并预览。
- 预览可切换原文与结果，显示规则命中次数及跳过原因；可粘贴其他文字测试。编辑预览文本、预览未保存规则均不会修改书籍或已保存规则。预览遵循当前总开关、单书开关及规则范围。
- 关闭全局开关，或关闭「本书应用净化」，即可恢复缓存原文。单书选择重启后保留。改变规则后，当前章节重新处理，停止正在进行的朗读；再次听书使用新结果。翻页/字号变化同样使用净化正文。阅读位置按章内比例恢复，文本长度变化可能改变具体页码；不会改写已有书签。
- 处理在后台任务中进行，每章总处理预算约 0.5 秒；超时、取消、输出超限时不发布半条规则的结果。正文/输出最多 800 万 UTF-16 单元，单条规则最多处理 10 万个匹配。净化后整章为空会显示原文并提示检查规则；错误或超限提示可在预览查看。
- 最多保存 100 条规则，JSON 文件上限 1 MB。导入本应用 `YueduPurification` 格式，新增规则默认停用，重复规则不重复添加；不覆盖原有规则，不扩大限定范围。规则单独导出，书架备份仍保存原始正文。跨设备需核对书籍/书源标识，从目标书籍的阅读设置重新指定范围；此处不宣称兼容 Legado 的替换规则文件。

## 书源管理工具

书源页支持按名称、网址、分组搜索，按分组及已启用/已停用/支持发现/检测失败/尚未检测筛选，并按导入顺序、名称或检测耗时排序。「管理」进入多选，全选只覆盖当前筛选列表；切换搜索或筛选清空选择。

批量操作包括启停、开关发现、替换分组、检测、导出所选和确认删除。整批修改先校验再原子保存；任一书源配置不满足启用要求时不部分启用。分组名最多 40 字，不使用逗号、分号或换行作为名称。设为未分组会清空原分组。导出保留完整规则与未知字段；删除书源不删除书架或已缓存正文。相同 `bookSourceUrl` 的重复导入仍更新现有配置并保留 ID，不按域名合并不同版本。

右上角支持粘贴 JSON 导入，由用户在文本框内粘贴，不自动读取剪贴板。沿用文件/网址导入的大小、数量、结构检查和逐项报告。

检测前输入书名或关键词，可选仅搜索，或搜索→第一本结果的目录→首章正文。按源顺序访问，每阶段超时 20 秒，可手动停止，进入后台停止。已停用书源使用临时启用的配置副本检测，不改变持久启停状态，不加入书架，也不批量缓存正文。结果区分通过、无搜索结果和失败，保存阶段、错误原因、耗时、关键词及时间。失败不会自动删除或停用；无结果不等于书源失效，首章失败可能需要登录或更换测试书名。

检测记录单独保存在 `source-checks.json`，不写入导出的书源规则。配置变化后旧结果不参与状态筛选；单纯启停保留记录，便于停用故障书源后继续定位。执行期间编辑或删除配置会丢弃迟到结果。检测页支持重试所选范围内的失败源。耗时是整次所选检测模式的总时间，比较时需留意模式不同；通过仅说明此次访问成功，不保证其他书籍或后续章节均可用。

## 发现页

发现页直接列出书源，轻点书源名称展开其分类、榜单等入口。支持按书源名称和分组筛选；分组来自 `bookSourceGroup`，支持逗号、分号及换行分隔。列表按 `customOrder` 升序排列，同序保留导入顺序。

仅展示已启用的文字书源，且 `exploreUrl` 非空、`enabledExplore` 未设为 false。只有搜索功能的书源不出现在分类列表里，但仍可通过右上角「搜索书籍」使用。无可用发现书源时显示配置说明及书源管理入口，不用内置书单代替书源内容。

展开时才执行分类规则，最多同时加载两个书源；空网址的分类项作为不可点击的小标题保留。收起或离开页面会取消未完成的分类加载，已完成分类在当前页面会话内复用；修改、停用和删除书源会使对应缓存失效。刷新分类可重试失败来源，单个来源错误不影响其他来源。分类点击后使用原有发现引擎加载分页书目并加入书架。

## 规则能力

规则解释器在 WebKit 中运行，覆盖以下形式。不同语法的细节仍以实现和回归测试为准，不等同于完整复刻 Android 运行环境。

| 类型 | 已实现形式 |
| --- | --- |
| CSS / Legado 选择链 | `@css:`、`@` 串联、`class.` / `id.` / `tag.` / `text.`，标准 CSS 及常见 Jsoup `:contains` / `:matches` / `:has` 等扩展 |
| 索引 | 正负索引、多个索引、范围切片和排除索引；CSS 与 JSONPath 切片遵循各自的语法 |
| 字段提取 | `text`、`ownText`、`textNodes`、`html`、属性值；支持当前元素提取 |
| XPath | `@XPath:` 或 XPath 路径，使用 WebKit 的 XPath 求值 |
| JSONPath | `@json:`、字段 / 引号键、通配符、正负索引、联合、切片、递归、过滤表达式及已实现的聚合函数 |
| 组合 | `&&` 合并、`\|\|` 回退、`%%` 交错，以及规则中的动态模板 |
| 变量 | `@put:` / `@get:`、`{{…}}`，书源、书籍和章节上下文 |
| 脚本 | `@js:`、`<js>…</js>`、规则与脚本串联、内联或网址形式的 `jsLib` |
| 正则 | `##` 删除 / 替换、捕获组、首次匹配形式、正则列表提取、正文 `replaceRegex` |

例如：

```json
{
  "bookList": "class.book-list@tag.li",
  "name": ".bookname@a@text##书名：",
  "author": "span[0]@a@title",
  "bookUrl": "tag.a.-1@href"
}
```

JSON 列表可使用 `@json:$.books[*]`，列表字段相对于当前项，例如 `$.name`、`$.url`。字段正则支持 `##作者：(.+)##$1`；对 `@html` 的替换发生在最终正文转为纯文本之前。Java 正则的一些常见形式会转换，但不保证支持所有 Java 正则扩展。无效选择器或表达式会在执行时报告错误。

普通 HTML 在脱离运行页面的文档中解析，不把远程 DOM 插入宿主页面，也不自动执行网页脚本。书源明确要求 `webView` / `webJs` 时，使用独立的网页浏览环境获取渲染结果。

## 请求、登录与运行状态

请求网址支持 `{{key}}`、`{{page}}` 和脚本表达式；可附加 JSON 请求选项，例如：

```json
{
  "searchUrl": "/search,{\"method\":\"POST\",\"body\":\"keyword={{key}}&page={{page}}\",\"charset\":\"GBK\"}"
}
```

支持 GET / POST / HEAD、字符串或 JSON 正文、字符集、请求头、超时、重定向控制、请求脚本以及网页渲染选项。查询和表单内容按指定字符集编码；支持 UTF-8、GBK / GB2312 / GB18030、Big5 等系统可识别编码。

`header` 可为对象、JSON / 对象文本或返回请求头的脚本；与登录头、请求级头合并后发送。支持 `User-Agent`、`Referer`、`Cookie`、`Authorization` 等站点需要的字段，拒绝控制字符以及 `Host`、`Content-Length` 等连接管理字段。跨主机重定向会移除原始认证头和 Cookie，再应用目标主机的 Cookie。

Cookie 按书源隔离并遵循域名、路径、过期和安全属性保存。`enabledCookieJar` 控制 HTTP 响应 Cookie 的自动保存；已有 Cookie、脚本 Cookie API 和网页登录 Cookie 同步独立保留。书源变量、登录信息、脚本缓存和书籍上下文也按书源持久化；脚本的文件接口仅能读取其自身下载缓存，不能访问任意应用文件。

「登录与设置」呈现 `loginUi` 的输入框、选项和操作按钮，并提供书源变量编辑。登录脚本、验证码输入、图片验证码和网页验证可从该入口完成。普通搜索 / 阅读不会自动弹出登录浏览器；需要交互时会提示用户进入设置。`loginCheckJs` 可检查响应并更新登录状态。应用不自动调用付费购买规则，也不替用户购买章节。

## JavaScript 宿主和系统工具

脚本可使用适配后的 `java`、`source`、`book`、`chapter`、`cookie`、`cache` 接口，处理网络请求、规则提取、变量、响应对象、登录状态和缓存。`jsLib` 可载入内联脚本或通过受限网络接口下载库；远端库的实际版本及运行行为仍需按站点验证。

系统工具提供 Base64 / Hex、字符编码、MD5 / SHA 摘要、AES / DES / 3DES、HMAC、RSA、简繁转换、时间格式、中文章节号和 UUID。密码学使用 CommonCrypto / Security，字体映射使用 CoreText，图像像素读取使用 ImageIO / CoreGraphics；无第三方运行依赖。

为现有书源提供一组 Java 风格适配，包括 `Cipher` / `Mac`、密钥和 IV、Base64、集合、字符串、字节流、Jsoup 常用方法，以及部分 Android Cookie / Bitmap 接口。`Packages` / `JavaImporter` 仅暴露这些明确实现的对象；没有 JVM、任意 Java / Android 类加载、反射或操作系统命令执行。

字体接口已实现基于字形轮廓的映射，但**未验证真实字体混淆站点**；动态远端脚本库也**未完成实站验证**。这些接口的存在不能作为所有相关书源可用的证明。

## 网络与执行边界

每次规则操作使用独立 WebKit 运行上下文。宿主页面通过 CSP 禁止直接网络连接、远程图片和框架加载，并禁止导航；脚本网络请求必须经过明确的原生桥接接口。登录 / 渲染网页使用另一个浏览环境，站点页面不会获得书源宿主桥接。

为支持用户定义的普通 HTTP 书源，工程启用了 ATS `NSAllowsArbitraryLoads`。这允许明文 HTTP；**HTTPS 的系统 TLS 证书验证仍保留**，没有接受任意证书或跳过证书验证的实现。

| 边界 | 当前上限 |
| --- | --- |
| 导入合集 | 50,000,000 字节、10,000 项 |
| 普通 HTTP 响应 / 请求正文 | 8,000,000 字节 |
| 普通 HTTP 超时 | 默认请求 30 秒、资源 60 秒；规则请求超时限制在 1–90 秒 |
| 单次规则操作 | 默认 120 秒；在线搜索、换源目录和试读 30 秒；书源检测每阶段 20 秒；交互登录 600 秒，可取消 |
| 单次规则操作网络请求 | 300 次原生请求调用 |
| 目录或正文分页 | 各最多 200 页 |
| 目录 | 最多 20,000 章 |
| 单次选择结果 | 30,000 项；JSONPath 嵌套最多 64 层 |
| 搜索 / 发现每页 | 每源最多 100 条结果；综合搜索同时处理最多 3 个源 |

达到限制会停止相应操作并报告错误。网页渲染的资源加载由独立 WebKit 处理，不能把普通 URLSession 的正文上限理解为整页所有子资源的总下载限额。

## 本地流程与验证记录

在工程根目录运行：

```sh
python3 scripts/demo_source_server.py
```

在 **iPhone 模拟器**的「书源 → ＋ → 从网址导入」输入 `http://localhost:8080/source.json`，随后到发现页搜索「春日」，把《春日手记》加入书架并阅读两章。两章为原创测试内容。已打开的正文可在关闭服务或停用书源后复读。

`/mixed-sources.json` 提供包含普通文字源、脚本文字源、无效项和漫画源的合成合集，用于检查逐项导入报告与原始配置保留。`Yuedu/Resources/example-source.json` 默认停用；本地服务返回启用版本。

`/online-sources.json` 提供在线搜索验证用的三个书源，覆盖页内重复、分页新增、忽略分页的重复页、首次失败后重试恢复，以及同名同作者的版本选择。数据为合成测试书目，不代表第三方网站。

服务默认仅监听 Mac 回环地址，模拟器可访问 Mac 的 localhost；实体 iPhone 的 localhost 指向手机自身，需另行提供手机可访问的服务。

静态能力分析脚本为 `scripts/analyze_source_collection.py`，只分析 JSON 和脚本文本，不执行第三方代码。[静态规则烟测](../scripts/LEGADO_RULE_SMOKE.md)可重现 5,118 条规则在合成 HTML / JSON 上的解析检查。构建、组件测试、模拟器流程及其实际结果统一见 [VALIDATION.md](VALIDATION.md) 的分阶段记录。本地服务测试、静态语法检查或配置逐字段比对，均不能替代 342 个真实站点的完整验证。

`/switch-sources.json` 提供换源验证书源：原源第二章为空、备用源插入序章并更改数字章名、试读先失败再恢复、同名异作者需手动确认。`/switch/reset` 重置试读请求状态。仅用于本地测试。

`/cache-source.json` 提供缓存管理测试书源，含延迟章节和首次空正文，配合 `/cache/reset`、`/cache/stats` 验证范围下载、暂停恢复及仅重试失败章节。仅用于本地测试。
