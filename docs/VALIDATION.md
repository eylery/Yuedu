## 2026-10-22：三项架构改造

### 正文与书架元数据拆分

- `library.json` 使用存储版本 2，仅保存书籍/章节元数据、进度、书签、统计以及正文引用；正文位于 `chapter-content/<UUID>`，包含 UTF-8 字节数、非空标志和 SHA-256 摘要。目录、书架和缓存统计只读元数据，阅读按章节在后台读取并校验正文。
- 章节文件不可变；串行存储队列先原子写入新正文，最后原子替换元数据，成功后才发布内存状态。进度/书签变更重用现有文件。写入失败回收本次新文件，原状态和原正文保持不变；启动时清理中断写入产生的无引用章节文件。
- 旧 JSON 自动迁移，原始文件逐字节保存在 `library-before-body-split.json`。迁移未完成时保留旧书库阅读能力，后续保存可重试；无法解析的书库仍禁止覆盖。该恢复副本会占用额外空间，升级不自动删除它。
- 清理缓存或删除书籍在元数据提交成功后回收失去引用的正文文件；本地书不受在线缓存清理影响。备份仍使用原有可移植格式，导出包含真实正文而非设备路径；导出与文件回收通过同一串行队列协调。正文缺失或摘要不符会报错，不生成悄悄缺章的备份。
- 存储提交仍保留同步成功/失败语义，UI 需要等待元数据提交确认；此次消除了全部正文的反复编码与写入，并未把所有书库元数据事务改成异步 API。

### 可复用书架网格

- 书架使用 UICollectionView 与按书籍 UUID 标识的 diffable data source；封面、标题和状态视图随单元格复用。顶部继续阅读、筛选和管理工具作为同一滚动容器的头部。
- 保留分组、状态、排序、置顶、长按菜单、批量操作与下拉追更；选择以 UUID 记录，复用时重置辅助功能与事件回调。按可用宽度显示 2–6 列，适配横屏；隐藏书架仍延后刷新。
- 增加 600 本书的滚动/旋转测试，确认实际可见单元格数量有界，滚动到底部仍能取得正确单元格。

### 后台分页与 HTTP 响应处理

- CoreText 整章分页在可取消的后台任务中执行，每页检查取消。切章、字体设置、阅读模式和视口变化使用请求版本校验；过期结果不能覆盖新章节或新尺寸。分页未完成时保留原进度，完成后按字符位置恢复页码。
- 后台仅回传页范围；绘制层持有独立的 framesetter 并在可见页面间复用，不跨线程共享 Core Text 布局对象，遵循 [Apple 的线程使用约定](https://developer.apple.com/documentation/CoreText)。绘制不再为每页创建整章 framesetter。分页模式下清空隐藏的滚动 UILabel，避免它继续在主线程进行重复的整章排版；阅读层与功能栏层级保持不变。
- HTTP 流式字节收集、字符集解码及 Base64 转换移入后台任务；取消传递到底层 URLSession。Cookie、书源限流及重定向策略仍由主线程协调，保留跨站凭据隔离、重定向限制和 8 MB 流式上限。

换源专项额外发现并修复：未入库的候选版本目录应使用独立快照，不能跟随书架查找后被清空；手动选章回调同样保持候选索引，实际书架目录继续按章节 ID 同步。

### 后续优先项（本轮未进行架构改造）
