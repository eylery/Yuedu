# 静态书源规则离线烟测

在 macOS（已安装 Xcode 命令行工具）上运行：

```sh
python3 scripts/smoke_legado_rules.py build/SourceImportInvestigation/collection.json --report build/static-rule-smoke.json
```

脚本使用系统 WebKit 和项目自有 `rules.js`，只向规则解析器提供合成 HTML / JSON；不会导航到书源网站，不执行书源 JavaScript。它检查文字源的搜索、详情、目录、正文核心字段，排除脚本、`@put` / `@get`、`{{...}}` 与旧式 `{$...}` 模板。临时规则输入文件位于私有临时目录，运行结束即删除。

结果仅记录数量、输入文件及规则库 SHA-256，以及失败条目的数组下标、字段路径和固定错误类别。不会输出书源规则、脚本、请求头、网址或凭据。默认整体超时为 180 秒；返回码 0 表示本次烟测无解析异常，1 表示发现异常，2 表示检查未完成。

## 本次结果

详见同目录 `legado_rules_smoke_result.json`。本地合集共有 391 项，其中 342 个文字源。早期临时程序检查了 5,135 个静态核心字段；整理后的版本进一步排除其中 17 个旧式 JSON 模板，因此严格静态集合为 **5,118 个字段**。两次检查范围不同，不能直接按同一分母比较。

2026-09-24 的重现结果：**5,118 / 5,118 个字段完成，解析异常 0，脚本执行钩子调用 0**；其中 4,658 项使用合成 HTML，460 项使用合成 JSON。报告保存了合集和规则库的哈希，便于确认后续是否使用相同输入。

**合成内容上的语法烟测不能证明规则会命中真实网站，也不能证明书名、目录、正文或翻页结果正确。** 上下文类型依据规则推断，缺少匹配节点时可以返回空结果。该脚本不验证网络、登录、动态脚本、站点可用性或完整 Legado 兼容性；这些需要另行使用受控响应 fixture 和实际授权场景验证。
